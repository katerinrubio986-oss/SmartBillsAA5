# SmartBills API

## Descripción

SmartBills API es un servicio web desarrollado con Node.js y Express para administrar los ingresos y gastos de un negocio.

## Tecnologías

- Node.js
- Express
- JavaScript

## Instalación

1. Clonar el proyecto.
2. Ejecutar:

```bash
npm install
```

3. Ejecutar:

```bash
node index.js
```

Servidor:

```
http://localhost:3000
```

## Endpoints

### Inicio

GET /
